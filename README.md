# Movie Explorer

Movie Explorer is a React-based web application for discovering movies and TV shows. Users can browse popular shows, search for specific titles, and view detailed information about each show.

## Features

* Browse popular TV shows
* Search for movies and TV shows
* View movie/show details
* Rating and release date information
* Genre information
* Show summary
* Responsive design
* Loading and error states
* No-results handling
* Active navigation links

## Technologies

* React
* Vite
* React Router
* JavaScript
* CSS
* TVMaze API

## API

This project uses the TVMaze API to fetch TV show data and search results.

## Getting Started

Clone the repository and install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will run locally through the Vite development server.

## Build

To create a production build:

```bash
npm run build
```

To check the project with ESLint:

```bash
npm run lint
```
